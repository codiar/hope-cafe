# Hope Cafe

موقع القائمة الرقمية والطلب المباشر لهوب كافيه.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى المستودع.
2. استخدم فرع `main`.
3. من Settings → Pages اختر GitHub Actions.
4. بعد نجاح Workflow سيظهر رابط الموقع.

حقوق الموقع محفوظة لهوب كافيه، مع نسبة تطوير الموقع إلى كوديار تك في التذييل.
